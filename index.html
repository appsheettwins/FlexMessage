ปุ่มกดและลิงก์ (Buttons)

คุณสามารถเพิ่มปุ่มได้ตามต้องการ เช่น ปุ่มกรอกฟอร์มสมัคร, ปุ่มดูรายชื่อผู้สมัคร และปุ่มแชร์ให้เพื่อน

ตัวอย่างการแสดงผลใน LINE

โค้ด Flex Message JSON
นำโค้ด JSON นี้ไปวางใน LINE Official Account Manager (เมนูข้อความตอบกลับอัตโนมัติ > Flex Message) หรือใช้ใน LINE Flex Simulator ได้ทันที

โปรเจกต์ที่บันทึกไว้

นำเข้าโค้ด JSON กลับมาแก้ไข

วางโค้ด Flex Message JSON (รูปแบบ Bubble) ที่คุณเคยสร้างไว้ เพื่อดึงข้อมูลกลับมาแก้ไขในฟอร์ม:

แชร์การ์ดเข้า LINE (Share Target Picker)

ข้อกำหนดก่อนกดแชร์เข้า LINE:

1. ต้องนำไฟล์เว็บนี้ขึ้นโฮสติ้ง HTTPS (เช่น GitHub Pages, Vercel, Netlify) และนำไปตั้งค่าเป็น Endpoint URL ใน LINE Developers Console

2. ต้องเปิดใช้งาน Share Target Picker ในตั้งค่า LINE Login / LIFF App ของคุณ

ลิงก์สำหรับปุ่ม "แชร์ให้เพื่อน" ในการ์ด

ลิงก์นี้จะฝังข้อมูลการ์ดและ LIFF ID ไปด้วย เมื่อเพื่อนกดปุ่มแชร์ในการ์ด หน้าเลือกเพื่อนใน LINE จะเด้งขึ้นทันทีโดยไม่แสดงหน้าแก้ไขการ์ด

บันทึกข้อมูลเรียบร้อยแล้ว
